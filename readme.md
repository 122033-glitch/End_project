Простий калькулятор

Суть програми - виконувати облічення.
Що в ньому такого:
1. Інтерактивна сітка кнопок - зручне розташування цифр і операторів.
2. Захист від помилок - через те що калькулятор інтерактивний, введення з клавіатури неможливе, що дозволяє запобігти помилкам зі сторони користувача(наприклад якщо користувач буде вводити не числа). Також якщо спробувати поділити на 0, калькулятор не вилетить, а тільки виведе в поле вводу "Помилка".
3. Стилізація - додає сучасного вигляду завдяки вибранному фону та шрифту.
